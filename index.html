AWS Secure Cloud Architecture — Defense in Depth

Production-grade 3-tier AWS architecture built with security controls at every layer. Designed to demonstrate how defense-in-depth protects against real-world threats.

→ Click any component to learn what it does

  • Multi-AZ VPC with public, app, and data subnet tiers — each fully isolated
  • NACLs + Security Groups with SG-to-SG referencing — no IP-based rules
  • SSM Session Manager — zero SSH, no open ports, full audit trail
  • Secrets Manager with auto-rotation — credentials never in code
  • GuardDuty + CloudTrail — 24/7 threat detection and audit logging
  • Security control mapping to CIS, AWS Well-Architected, and NIST CSF
